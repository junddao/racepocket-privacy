# racepocket-privacy

Race Pocket 앱·웹의 정책·지원 페이지. GitHub Pages로 서빙된다.

## 페이지

| 경로 | 내용 | 용도 |
|------|------|------|
| `/` | 개인정보 처리방침 (한국어) | App Store·Google Play 개인정보처리방침 URL |
| `/en/` | Privacy Policy (English) | Apple 심사 대응 |
| `/data-deletion/` | 데이터 삭제 안내 | Google Play 데이터 삭제 URL |
| `/support/` | 고객 지원 / FAQ | App Store 지원 URL |

## 배포

`main` 브랜치에 푸시하면 GitHub Pages가 자동 배포한다.
Settings → Pages → Source: `main` / `(root)`.

- 개인정보 처리방침: https://junddao.github.io/racepocket-privacy/
